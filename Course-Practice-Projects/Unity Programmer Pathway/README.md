## Unity Programmer Pathway

The **Unity Programmer Pathway** folder contains projects I completed while working through the Unity Programmer Pathway. Each project in this folder reflects a key learning milestone in my journey, with additional customizations and improvements that I made to enhance the original projects.

### Projects Included:
- Balloon Fly
- Basic Soccer
- Catch The Ball
- Clicky Crates
- Driving Simulator
- Error Project Debug
- Feed The Animal
- Mod The Cube
- Simple Plane Programming
- Sumo Battle Royale
- Whack-a-Food

These projects are an excellent representation of the skills and techniques I learned, including Unity development, C# scripting, physics interactions, and more.

Feel free to explore the folder for code samples, implementations, and the improvements I made along the way!
