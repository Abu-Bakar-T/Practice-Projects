# Practice Projects

This repository contains various projects I created for learning purposes. The projects are organized into two main folders:

- [Guided Projects](#guided-projects)
- [Course Practice Projects](#course-practice-projects)

## Overview

The **Practice Projects** repository showcases my journey in learning game development. It includes a mix of guided projects and projects developed during coursework. Each project emphasizes different aspects of game design, programming, and user experience.

The **Guided Projects** folder includes projects that I developed by following online tutorials and courses. Each project is a replication of an existing game or concept, with unique additions and enhancements made by me. Examples include games like Color Roller Splat, Duet Game, and Tic Tac Toe.
